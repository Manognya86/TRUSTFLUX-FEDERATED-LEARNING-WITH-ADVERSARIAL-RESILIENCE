# TRUSTFLUX-FEDERATED-LEARNING-WITH-ADVERSARIAL-RESILIENCE
TrustFlux: A Byzantine-robust federated learning framework for medical imaging. Defends against 5 model poisoning attacks using Multi-Krum aggregation, adaptive per-client trust scoring, and SHA-256 Merkle audit trails. Real-time Plotly Dash monitoring dashboard. Fully containerised with Docker Compose. Built for Trustworthy AI.
